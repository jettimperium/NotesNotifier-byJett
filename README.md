# 📋 Prack Notes Bot

Discord-бот для расписания праков и турниров. В канале висит таблица с
кнопками, а за 20 минут до сбора бот присылает игрокам с нужной ролью
напоминание в личные сообщения.

## Что умеет

- Показывает таблицу с колонками **№ · Название · Время сбора · Время матча ·
  Доп. информация**.
- **Добавить информацию** — форма с названием, MMR, временем сбора, временем
  матча и комментарием.
- **Изменить информацию** — выбор нужной строки и редактирование.
- **Очистить информацию** — удаление таблицы с подтверждением.
- **Напоминания в ЛС** — за 20 минут до сбора всем участникам с указанной
  ролью. Если несколько сборов попадают в одно окно, придёт одно сообщение
  со всеми записями.
- Данные хранятся в SQLite и не пропадают после перезапуска бота.
- Панель с кнопками работает после перезапуска (persistent view).

## Быстрый старт

### 1. Создайте приложение и бота

1. Откройте <https://discord.com/developers/applications>.
2. **New Application** → введите название → **Create**.
3. Слева **Bot** → **Reset Token** → скопируйте токен.
   Никому его не показывайте. Если токен утёк — сразу сбросьте его.
4. На этой же странице включите **Server Members Intent** в разделе
   **Privileged Gateway Intents**. Без него бот не сможет рассылать ЛС
   участникам роли.
   - Message Content Intent **не нужен**.

### 2. Пригласите бота на сервер

1. Слева **OAuth2 → URL Generator** (или **Installation**).
2. Scopes: `bot` и `applications.commands`.
3. Permissions: **View Channels**, **Send Messages**, **Embed Links**,
   **Read Message History**. Администратор не обязателен.
4. Откройте сгенерированную ссылку и добавьте бота на сервер.

### 3. Установите и запустите

Нужен Python **3.10+** (рекомендуется 3.12): <https://www.python.org/downloads/>.
При установке отметьте **Add python.exe to PATH**.

Самый простой способ на Windows:

1. Скопируйте `.env.example` в `.env`.
2. Откройте блокнотом именно `.env` (не `.env.example`) и вставьте токен:
   ```
   DISCORD_TOKEN=ваш_токен
   ```
   В `.env.example` токен вставлять нельзя — это публичный шаблон.
3. Дважды щёлкните `start.bat`. Он создаст `.venv`, установит зависимости
   и запустит бота.

> Окно с ботом должно оставаться открытым, пока бот нужен. Его можно
> свернуть, но не закрывать: при закрытии окна бот выключается и кнопки
> в Discord перестают отвечать. Второй экземпляр запускать не нужно.

Вручную:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
python bot.py
```

### 4. Настройте на сервере

В канале, где должна висеть таблица, выполните:

```
/setup notify_role:@Игроки editor_role:@Лидер
```

- `notify_role` — **обязательно**: роль игроков, которым приходят ЛС.
- `editor_role` — необязательно: кто может менять таблицу. Если не указать,
  менять смогут только администраторы.
- `channel` — необязательно: канал таблицы. По умолчанию текущий.
- `timezone` — по умолчанию `Europe/Moscow`.
- `remind_minutes` — по умолчанию `20`.

Пример с отдельным каналом:

```
/setup notify_role:@Игроки editor_role:@Лидер channel:#праки
```

После этого в канале появится панель с тремя кнопками.

> `/setup` может выполнить только владелец сервера или участник с правом
> **«Управлять сервером»**. Если команда не видна — обновите Discord
> (`Ctrl+R`) или перезапустите его. Если команда видна, но бот сообщает о
> нехватке прав — попросите владельца сервера выполнить настройку.
> В параметре `editor_role` можно указать роль, участники которой смогут
> менять таблицу без прав администратора.

### 5. Проверьте личные сообщения

Каждый игрок должен разрешить ЛС от участников сервера:

**Настройки Discord → Конфиденциальность и безопасность → Личные сообщения
от участников сервера → включить**.

Проверка со стороны организатора:

```
/test-reminder
```

Бот отправит вам тестовое напоминание в ЛС. Если пришла ошибка — включите
эту настройку у себя.

## Как пользоваться

### Добавить запись

1. Нажмите **«Добавить информацию»**.
2. Заполните поля:
   - **Название** — например, `20:00 без смурфов`;
   - **MMR / уровень** — например, `3 250 MMR`;
   - **Время сбора** — `19:40` или `24.10 19:40`;
   - **Время матча** — `20:00` или `24.10 20:00`; можно оставить пустым;
   - **Доп. информация** — комментарий, ссылка, требования.
3. Нажмите **Submit**. Таблица обновится сразу.

MMR показывается в колонке **«Доп. информация»** вместе с комментарием.
Полный текст комментария и MMR также видны при редактировании и в напоминании.

### Изменить запись

1. Нажмите **«Изменить информацию»**.
2. Выберите строку в выпадающем списке.
3. Исправьте поля и отправьте форму.

Если изменить время сбора, напоминание будет пересчитано. Если после
изменения до сбора осталось меньше 20 минут, бот пришлёт ЛС при ближайшей
проверке (в течение ~30 секунд).

### Очистить таблицу

1. Нажмите **«Очистить информацию»**.
2. Подтвердите действие кнопкой **«Да, очистить»**.

Удаляются все записи и все запланированные напоминания.

## Форматы времени

Бот принимает:

| Ввод | Значение |
|---|---|
| `19:40` | сегодня в 19:40 (если время уже прошло больше чем на 30 минут — завтра) |
| `сегодня 19:40` | сегодня |
| `завтра 19:40` | завтра |
| `24.10 19:40` | 24 октября в 19:40 |
| `24.10.2026 19:40` | с годом |
| `20:00 МСК` | слова «МСК» / «msk» игнорируются |

- Если у матча не указана дата, используется день сбора. Ночной матч
  (`23:50` → `00:20`) автоматически переносится на следующий день.
- Если время матча раньше времени сбора и это не ночной матч, бот попросит
  указать дату явно.
- Время в таблице и напоминаниях показывается в часовом поясе, указанном
  при `/setup`. По умолчанию — МСК.

## Напоминания

- Проверка запускается каждые 30 секунд.
- За 20 минут до **времени сбора** (настраивается) бот отправляет ЛС каждому
  участнику роли `notify_role`.
- Боты и участники без роли в рассылку не попадают.
- Если у игрока закрыты ЛС, бот не сможет доставить сообщение — это
  фиксируется в логе. Напоминание при этом считается отправленным, чтобы не
  спамить остальных.
- Если бот был выключен в момент напоминания и включился уже после сбора,
  устаревшее напоминание не отправляется.
- **Бот должен быть онлайн 24/7**, иначе напоминания не придут. Держите его
  на домашнем ПК, мини-ПК, VPS или хостинге для ботов.

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/setup` | Управлять сервером | Настраивает канал, роли, часовой пояс и время напоминания; публикует панель |
| `/panel` | Админы и роль редакторов | Обновляет панель или восстанавливает её, если сообщение удалили |
| `/test-reminder` | Админы и роль редакторов | Присылает тестовое напоминание в ЛС |

Кнопки на панели доступны администраторам и роли `editor_role`
(если она задана). Все проверки прав выполняются на стороне бота, а не
только скрытием кнопок.

## Настройки в `.env`

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_TOKEN` | — | Токен бота, обязателен |
| `DEFAULT_TIMEZONE` | `Europe/Moscow` | Часовой пояс по умолчанию для `/setup` |
| `DEFAULT_REMIND_MINUTES` | `20` | Значение по умолчанию для `/setup` |
| `MAX_EVENTS` | `25` | Максимум строк в таблице (не больше 25) |
| `DB_PATH` | `data/notes.db` | Файл базы данных |
| `LOG_PATH` | `data/bot.log` | Файл лога |

Время напоминания и часовой пояс задаются **на сервере** через `/setup`;
переменные окружения задают только значения по умолчанию.

## Где хранятся данные

- `data/notes.db` — настройки серверов и записи.
- `data/bot.log` — лог (ротация: 1 МБ, 3 файла).

Для резервной копии достаточно остановить бота и скопировать `data/notes.db`.
Файл `.env` и папку `data/` не выкладывайте в публичный репозиторий.

> Проект лежит в OneDrive. SQLite обычно работает нормально, но если
> синхронизация OneDrive мешает (ошибки `database is locked`), перенесите
> проект в обычную папку, например `C:\prack-notes-bot`, или задайте
> `DB_PATH` вне OneDrive.

## Возможные проблемы

**Команды не появляются**
- Подождите несколько минут и перезапустите Discord.
- Проверьте, что при приглашении был scope `applications.commands`.
- Посмотрите лог: при старте бот пишет, сколько команд синхронизировал.

**`PrivilegedIntentsRequired`**
- В Developer Portal включите **Server Members Intent** и перезапустите бота.

**Напоминания не приходят**
- У игроков включены ЛС от участников сервера?
- Бот онлайн?
- Роль в `/setup` та, что выдана игрокам?
- Время сбора указано в будущем и в правильном часовом поясе?
- Проверьте `/test-reminder` и `data/bot.log`.

**`ModuleNotFoundError`**
- Запускайте через `start.bat` или активируйте `.venv` и установите
  зависимости: `pip install -r requirements.txt`.

**`LoginFailure` / неверный токен**
- Скопируйте токен заново в `.env` без пробелов и кавычек.

**Бот не может отправить панель**
- Нужны права: просмотр канала, отправка сообщений, встраивание ссылок,
  история сообщений. После исправления выполните `/panel`.

**Два бота отправляют напоминания**
- Запущен второй экземпляр. Остановите лишний процесс.
